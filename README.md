# Practical 11: React Router Navigation

**Aim**: Develop a React application that uses `BrowserRouter`, `Route`, and `Link` to navigate between Home, About, and Contact pages without reloading the entire webpage.

## Key Features
- **Client-Side Routing**: Navigates between views seamlessly without browser refreshes.
- **Component Hierarchy**: `BrowserRouter` wrapping `Navigation` bar and `Routes` container.
- **Page Components**: `Home`, `About`, and `Contact` with active link indicators.

## How to Run
```bash
npm install
npm run dev
```
